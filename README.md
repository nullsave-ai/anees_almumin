# أنيس المؤمن

1. ثبّت Flutter 3.24 أو أحدث.
2. من مجلد المشروع: `bash setup.sh` (يولّد مجلد android ويطبّق الأذونات وإعدادات الإشعارات).
3. `flutter run`

ملاحظات:
- أوقات الصلاة تُحسب محليًا بالكامل (حزمة adhan_dart) وتعمل بدون إنترنت.
- نص القرآن يُحمَّل مرة واحدة لكل سورة من api.alquran.cloud ثم يُخزَّن على الجهاز.
- الإشعارات تُجدول لـ 14 يومًا قادمة وتُعاد جدولتها عند فتح التطبيق ويوميًا ولدى تغيير الإعدادات.
- لا يوجد أي Emoji في المشروع؛ كل الأيقونات من Material Icons.
