# أنيس المؤمن

1. ثبّت Flutter 3.24 أو أحدث.
2. `bash setup.sh` (يمكن إعادة تشغيله بأمان؛ يولّد android ويطبّق الأذونات ونسخ الأذان تلقائيًا).
3. `flutter run`

## أصوات الأذان
ضع ملفات mp3/ogg/wav في `assets/adhan/` بأسماء إنجليزية (مثل `mishary_alafasy.mp3`) ثم أعد البناء.
تُنسخ تلقائيًا إلى موارد أندرويد وتظهر في: أوقات الصلاة > الإعدادات > المؤذن وصوت الأذان مع معاينة.

## الأداء
تأثير الضبابية (blur) متوقف افتراضيًا ويُفعَّل من: الرئيسية > زر المظهر.

## ملاحظات
- أوقات الصلاة تُحسب محليًا (adhan_dart) وتعمل دون إنترنت.
- نص القرآن يُحمَّل مرة واحدة لكل سورة من api.alquran.cloud ثم يُخزَّن محليًا.
- الأيقونات من Phosphor وكلها معرّفة في `lib/core/icons.dart` (لتعديل أي اسم من مكان واحد).
- لا Emoji في المشروع.
