# أنيس المؤمن

1. ثبّت Flutter 3.24 أو أحدث.
2. `bash setup.sh` (يولّد android ويطبّق الأذونات والإشعارات ويزامن أصوات الأذان).
3. `flutter run`

## أصوات الأذان
ضع ملفات mp3/ogg/wav في `assets/adhan/` بأسماء إنجليزية صغيرة (مثل `mishary_alafasy.mp3`)،
ثم `bash sync_adhan.sh` وأعد بناء التطبيق. تظهر تلقائيًا في: أوقات الصلاة > الإعدادات > المؤذن وصوت الأذان
(مع معاينة). المشروع لا يتضمن ملفات صوتية.

## ملاحظات
- أوقات الصلاة تُحسب محليًا (adhan_dart) وتعمل دون إنترنت.
- نص القرآن يُحمَّل مرة واحدة لكل سورة من api.alquran.cloud ثم يُخزَّن محليًا.
- الإشعارات تُجدول 14 يومًا وتُعاد جدولتها يوميًا وعند فتح التطبيق وتغيير الإعدادات.
- الوضع الليلي: زر في الرئيسية (الافتراضي يتبع النظام).
- الأذكار: عرض بطاقات (ذكر لكل صفحة مع عدّاد حلقي وانتقال تلقائي) أو قائمة، من زر في أعلى الصفحة.
- لا Emoji في المشروع؛ الأيقونات من Material Icons.
